# 書籍簡報資料結構標準規範 (SCHEMA.md)

本知識庫所有書籍導讀簡報均依據「麥肯錫顧問風格（McKinsey Style）」編制，符合金字塔原理，且具備三段式講者備忘稿。

## 欄位結構說明

## 嚴格守則
1. **完全忠於來源**：僅能使用來源電子書內文提及之事實、案例與數據；來源未提及處嚴禁推測，一律註明「原文未載」。
2. **金字塔原理標題**：所有 slide 的 `title` 必須是一句表達完整觀點的「結論句」，不可使用單純章名或主題名詞。
3. **資訊分組與留白**：每頁卡片群組不超過 3 個，避免視覺雜訊。

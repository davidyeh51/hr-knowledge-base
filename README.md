## 📌 核心特色

1. **雙軌結構化知識地圖（Dual-View Knowledge Map）**
   - **Notion「3.3 人資管理」架構**：完整映射 `3.3.1 人力資源管理`、`3.3.2 能源HR工作`、`3.3.3 選才`、`3.3.4 用才`、`3.3.5 育才`、`3.3.6 留才` 六大核心支柱與全部 22 個標準子模組槽位。
   - **原主題領域分類**：完整保留原有主題領域，並擴充納入 `AI 與未來組織（A2.5.4.5）`，首頁一鍵切換。
2. **全文關鍵字檢索引擎（Full-Text Instant Search）**
   - 支援即時關鍵字查詢、多關鍵字交集、Notion 3.3 模組或主題領域標籤快篩。
   - 搜尋結果即時高亮匹配文字，標註 Notion 編碼與頁碼，點擊一鍵直達該書特定投影片（如 `#s4`）。
3. **麥肯錫顧問風格 16:9 簡報（Pyramid Principle + SVG + Redrawn Art）**
   - **結論先行**：每頁標題即為本頁核心結論句，非單純主題詞。
   - **圖表優先與視覺重繪**：內建向量 SVG 資訊圖表引擎（坐標曲線、柱狀/條形圖、漏斗圖、矩陣圖、架構阻力圖）與重新繪製的書籍主題視覺配圖。
   - **三段式講者備忘稿（按 `N` 鍵呼出）**：① 本頁結論 ② 補充說明（來源未載標註「原文未載」） ③ 下一頁轉場。
4. **極致閱讀與演講體驗**
   - 鍵盤快捷鍵：`→` / `空白` 下一頁、`←` 上一頁、`N` 講稿模式、`G` 目錄導航、`F` 全螢幕、頂部一鍵列印/匯出標準 1280×720 向量 PDF。

## 🛠️ 未來資料擴充架構（三步驟快速擴充）

1. **準備簡報資料 JSON**：在 `data/decks/` 新增簡報檔（如 `b9.json`），遵照 `docs/SCHEMA.md` 規範（支援可選 `svg` 向量圖表與 `image` 重繪配圖）。
2. **登記至雙軌目錄**：在 `data/catalog.json` 的 `decks` 陣列加入一筆配置，同時標明原分類 `domain` 與 Notion 編碼 `notion` / `notionSub`。
3. **一鍵重新建置**：執行 `python build.py`，自動更新首頁雙軌知識地圖、獨立簡報 HTML 與全文搜尋索引 `search-index.json`。

# 人力資源管理知識庫 (HR Knowledge Base)

> 專為中高階管理者設計的現代人力資源管理決策與學習平台。精選 6 本經典人資著作，依據**麥肯錫顧問風格（McKinsey Style）**提煉 10 分鐘高階導讀簡報（金字塔原理結論標題、架構圖、逐章重點、章節脈絡、總結行動與三段式逐頁講稿），具備全域關鍵字即時檢索與結構化知識地圖。

🌐 **線上網站**：[https://davidyeh51.github.io/hr-knowledge-base/](https://davidyeh51.github.io/hr-knowledge-base/)

---

## 📌 核心特色

1. **結構化知識地圖（Knowledge Map）**
   - 覆蓋**人資通論、策略與顧問視角、薪酬與人才機制、HR 數位化**四大核心領域。
   - 預留擴充節點：已規劃**組織行為學（對應 A2.5.4.2）**與**高績效團隊（對應 A2.5.4.3）**。
2. **全文關鍵字檢索引擎（Full-Text Instant Search）**
   - 支援即時關鍵字查詢、多關鍵字交集、領域標籤快篩。
   - 搜尋結果即時高亮匹配文字，點擊一鍵直達特定書籍的特定投影片（如 `#s4`）。
3. **麥肯錫顧問風格 16:9 簡報（Pyramid Principle Slides）**
   - **結論先行**：每頁標題即為本頁核心結論句，非一般主題詞。
   - **圖表優先與留白**：每頁最多 3 個資訊群組，避免資訊過載。
   - **三段式講者備忘稿（按 `N` 鍵呼出）**：
     - ① 本頁結論
     - ② 補充說明（來源無記載嚴格標記「原文未載」）
     - ③ 下一頁轉場
4. **極致閱讀與演講體驗**
   - 鍵盤快捷鍵：`→` / `空白` 下一頁、`←` 上一頁、`N` 講稿模式、`G` 目錄導航、`F` 全螢幕、支援瀏覽器一鍵列印/匯出為標準 PDF。

## 🛠️ 未來資料擴充架構（三步驟快速擴充）

本專案採用**數據驅動（Data-Driven）的靜態生成架構**，無繁雜依賴，新增書籍或知識模組僅需三步驟：

```
hr-knowledge-base/
├── build.py                  # 靜態站點建置器
├── data/
│   ├── catalog.json          # 領域分類與書籍登記目錄
│   └── decks/
│       ├── b1.json ~ b6.json # 各書籍簡報 JSON 資料
│       └── b7.json (擴充範例)
├── decks/                    # 自動產生的個別簡報靜態 HTML
├── assets/                   # CSS 樣式與搜尋、演講控制 JS
├── search-index.json         # 全文檢索索引
└── index.html                # 入口首頁（知識地圖 + 搜尋引擎）
```

### 擴充步驟：

1. **準備簡報資料 JSON**：
   在 `data/decks/` 目錄新增書籍簡報檔案（例如 `b7.json`），遵照 `docs/SCHEMA.md` 標準結構（包含 cover、architecture、chapter、flow、summary、appendix 及 notes 講稿）。
2. **登記至目錄清單**：
   在 `data/catalog.json` 的 `decks` 陣列加入一筆配置：
   ```json
   {
     "id": "b7",
     "file": "b7.json",
     "slug": "high-performance-teams",
     "domain": "team"
   }
   ```
3. **一鍵重新建置**：
   在根目錄執行：
   ```bash
   python build.py
   ```
   建置器將自動完成：
   - 產生 `decks/high-performance-teams.html` 獨立 16:9 簡報頁。
   - 抽取全書所有標題、結論、亮點與講稿，注入 `search-index.json`。
   - 更新 `index.html` 首頁知識地圖與統計數字。
